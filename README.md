# かけいろ / Kakeiro

銀行・クレジットカード・証券・現金をまとめて管理する、iPhone向けの家計簿・資産管理アプリです。SwiftUIで実装し、iOS 17以降に対応しています。

`/Users/adachi/Developer/Kakeiro` に作成した独立したGitリポジトリです。Yumeguri・Tabioriへの依存はありません。

GitHubの非公開リポジトリ：[sh-adachi/Kakeiro](https://github.com/sh-adachi/Kakeiro)。

**v0.2では自動連携を主軸に、更新ボタン・日本時間0時のサーバー定期取得・取得済みデータのiPhoneへの反映を実装しています。API・サーバーは未契約のため、実口座の自動取得はまだ有効ではありません。** 手動管理・CSVと架空データでの検証は契約なしで利用できます。

Moneytree LINKは初期費用・月額料金の見積もりが必要です。完全無料の本番連携は確認できていません。[費用・契約・利用者側の準備一覧](Docs/ConnectionSetupChecklist.md)、[サーバー導入手順](Docs/BackendSetup.md)を参照してください。

## できること

- **自動連携**：公開クライアントのOAuth PKCE認証、手動更新要求、毎日0時JSTの更新開始、重複防止、失敗時の前回データ保持。0時の完了やiPhoneへの即時反映は保証しません。
- **ホーム**：純資産・資産合計・カード負債、月別収支、予算の残り、カテゴリ別支出を表示。
- **明細**：収入・支出・口座間振替の追加・編集・削除。月と種類による絞り込み、お店・カテゴリ・口座の検索。
- **資産**：銀行・カード・証券・現金口座の追加・編集・削除。開始残高と明細から残高を計算。
- **証券の評価額**：口座全体の円換算評価額を手動で更新。評価額の変化を家計の収入として計上せず、開始残高を調整。
- **金融機関の登録先**：SBI証券、楽天証券、楽天銀行、三井住友銀行、三菱UFJ銀行、ゆうちょ銀行。カード会社名などは自由入力も可能。
- **予算**：全月共通の月額予算を保存。0円で予算表示を停止。
- **CSV取り込み**：テンプレート形式の収支明細を取り込み、完全に一致する同一口座・同日明細をスキップ。
- **バックアップ**：口座・明細・予算をJSONで書き出し、確認後に復元。

初回は空の家計簿です。「金融機関を連携して始める」から設定するか、手動口座・サンプルで始められます。設定のデータ削除は端末内のみが対象で、連携中は次回更新で再取得されます。

v0.1の画面例：[ホーム](Artifacts/home.png)、[資産](Artifacts/accounts.png)、[明細](Artifacts/transactions.png)、[連携](Artifacts/connections.png)、[初回画面](Artifacts/welcome.png)。表示された口座・金額はすべてテスト用の架空データです。

## お金の計算

自動取得口座は取得残高をそのまま使用し、過去明細を再加算しません。手動・CSVの補足は手動口座に保存します。返金・収入取消は元の収支から減算し、振替・カード返済は収支から除外します。取得対象外になった口座は最後の残高・明細を保持するため、口座別の取得日時を確認してください。

以下の開始残高・評価額の入力手順は手動口座向けです。
金額は日本円の整数で保存し、小数の丸め誤差を避けます。口座の開始残高・取引1件・月の予算の入力上限は1兆円。口座500件、明細100,000件までです。

資産口座は正の残高、カード未払額などの負債は負の残高で保持します。カードの登録画面では未払額を正の数で入力します。カード会社からの返金超過など、カードの貸方残高は負の未払額で表せます。

例：カードで3,000円の買い物をしたらカード口座の「支出」を登録。後日、銀行から3,000円引き落とされたときは、銀行からカードへの「振替」を登録します。振替を支出・収入に含めないため、支出は3,000円のままです。銀行と証券の間の資金移動も振替を使います。

開始残高は**記録を始める直前**の金額を入力してください。現在残高に過去の明細を加えると、その分が二重反映されます。資産画面の残高は登録されたすべての明細を反映し、月の切り替えには連動しません。未来日付の明細も残高へ反映されます。収支の月境界は日本時間です。

証券評価額は「資産 → 証券口座 → 現在の評価額を更新」で入力し、「口座の入力に反映」後、口座画面の「保存」で確定します。「キャンセル」なら評価額の変更も破棄します。評価額履歴・銘柄別保有数・NISA枠・売買損益・株価や為替の自動更新は未実装です。

## CSV

設定からテンプレートを「ファイル」に保存できます。UTF-8、見出しを含む6列です。金融機関固有のCSVを直接解析する機能はなく、この形式への変換が必要です。

```csv
date,type,amount,category,merchant,note
2026-09-01,expense,1280,food,スーパー,食材
2026-09-01,income,300000,salary,給与,9月分
```

- `date`：実在する日付を `yyyy-MM-dd` で指定。
- `type`：`expense` / `income`（`支出` / `収入` も可）。振替はアプリで登録。
- `amount`：1以上の半角整数。通貨記号・桁区切り・負数は不可。
- `category`：`food`、`daily`、`transport`、`housing`、`utilities`、`entertainment`、`health`、`shopping`、`salary`、`other`。アプリの日本語カテゴリ名も可。
- `merchant`：お店・内容（必須）。`note`：メモ（空欄可）。カンマ・改行・引用符を含む値は標準CSVの引用形式を使用。

ファイルは32MiB以下。不正な行がある場合は全体を中止し、既存明細を変更しません。口座・日付・種類・金額・分類・内容・メモが同じ明細は重複扱いです。同日にまったく同じ買い物を複数回した場合は、必要な明細を手動で追加してください。

## 保存と復元

データは `Library/Application Support/Kakeiro/ledger.json` に保存します。入力検証後にアトミックに書き込み、成功してから画面の状態を更新します。iOSのファイル保護を設定し、アプリが非アクティブの間は画面に家計情報を表示しない構成です。

読み込みに失敗した既存データを空の家計簿で上書きしません。エラー画面で再読み込みが可能です。バックアップの復元も全データを検証した後、現在の家計簿との置き換えを確認します。

JSONバックアップには家計情報が含まれ、アプリ独自のパスワード暗号化は行いません。自分で選んだ保存先で管理してください。クラウド同期・共有家計簿・Face IDアプリロックは未実装です。アプリを削除すると端末内のデータも削除されます。

## 金融機関との自動連携

6機関を対象に、Moneytree LINKなどの公式資料と接続条件を調査しています。楽天銀行の提携アプリ制限、証券会社の追加認証やパスキー制約があり、対応機関一覧への掲載だけではKakeiroから接続できるとは限りません。

認可処理・個人1人用バックエンド・同期処理は実装済みです。利用契約・検証用設定・6機関の対応範囲と金額の実照合は未完了です。円建て残高と明細が対象で、銘柄別表示・外貨換算は未対応です。銀行・証券のパスワードをKakeiroが直接取得する実装はありません。詳しい条件と公式資料は [金融機関連携の設計メモ](Docs/FinancialConnections.md) を参照してください。

## ビルドする

Xcodeで `Kakeiro.xcodeproj` を開き、Schemeを `Kakeiro`、実行先をiPhoneまたはiPhoneシミュレータにしてRunします。外部ライブラリやAPIキーなしで、手動管理機能を利用できます。

```sh
cd /Users/adachi/Developer/Kakeiro
open Kakeiro.xcodeproj

# 単体テスト
swift test

# シミュレータ用ビルド
bash Scripts/build_simulator.sh

# 画面操作テスト
bash Scripts/test_ui.sh

# 接続した実機へ、署名付きビルド・インストール・起動
xcrun xctrace list devices
bash Scripts/deploy_iphone.sh <iPhoneのUDID>
```

個人用の開発Teamを設定しています。Bundle Identifierは `dev.adachi.kakeiro`。別のApple Accountを使う場合は、XcodeのSigning & CapabilitiesでTeamとBundle Identifierを変更します。実機はMacとの信頼設定・開発者モードが必要です。開発用署名の期限が切れた場合は再ビルドしてください。App Storeへの公開は行っていません。
