# 自動連携の費用・契約・接続準備

確認日: 2026年9月7日。公開された公式情報と、Kakeiroで必要になる設定を整理したものです。API・サーバーは未契約で、提供元への問い合わせ、契約申込み、有料サービスの購入は行っていません。

## 無料でできる範囲

**アプリと同期サーバーのコード開発・ローカル検証は進められます。指定6機関の本番自動連携を継続して完全無料で使える方法は、今回の調査では確認できませんでした。** Moneytree LINKの公式案内は、初期費用と月額利用料が発生するとしています。金額は公開定額表ではなく、用途のヒアリング・NDA締結後の見積もりです。[公式費用FAQ](https://faq.getmoneytree.com/cost)

| 対象 | 費用・利用条件 |
| --- | --- |
| Kakeiroの開発・手動入力・CSV取り込み | 既存Mac/iPhoneを使って開発・ローカル動作確認を続けられる。実口座のAPI利用権とは別。 |
| iPhoneへの開発用インストール | 無料Apple AccountのPersonal Teamでも可能。ただしプロビジョニングは7日で期限切れとなり、再ビルド・再インストールが必要。配布や追加機能の利用条件はDeveloper Programを別途確認する。[Apple公式](https://developer.apple.com/help/account/basics/about-your-developer-account) |
| Moneytree LINK API | 初期費用＋月額利用料。最小料金・個人開発者の契約可否・個人専用アプリへの適用条件は未確認。 |
| LINKの検証環境 | 提供制度はあるが、今回確認した公開FAQは無料期間・無料上限を保証していない。本番環境はサービス契約後に提供される。[検証環境FAQ](https://faq.getmoneytree.com/test-environment) |
| 常時稼働する手持ちMac | 新たなクラウド利用料を抑える候補。電気・通信費は必要で、電源・ネットワーク・プロセスが動いていることが前提。スリープ中・停止中は定刻に処理できない。 |
| クラウドサーバー | 未選定・未契約。無料枠を利用できるかは、常時稼働、定期実行、暗号化保存、容量・通信量の条件を合わせて見積もる。クラウドの無料枠だけでLINK APIの費用はなくならない。 |

「個人向けと法人向けで費用が異なる」というMoneytreeの説明は、**開発するサービスの対象利用者**についての説明です。個人開発者が申し込めるという意味には読み替えません。[公式FAQ](https://faq.getmoneytree.com/price-difference-between-personal-and-business-usage)

## 無料サービスを代わりに使えるか

- **Moneytreeアプリ／Moneytree MCP**: MCPは無料プランでも利用可能と案内されています。ただし、これは対応AIアシスタントに読み取りを許可する機能の説明です。独自iPhoneアプリのLINK API用client ID発行や、サーバーからの毎日0時更新を許可する条件は確認できませんでした。無料MCPがあることを理由に、Kakeiroの本番連携基盤として利用可能とは扱いません。[MCP公式FAQ](https://help.getmoneytree.com/ja/articles/16010554-moneytree-mcp-よくある質問-faq)
- **LINK API Private**: 自社の業務用システムに銀行入出金データを取り込む製品です。個人の家計簿・カード・証券をすべて扱える、あるいは無料であるとは確認できていません。[自社利用FAQ](https://faq.getmoneytree.com/internal-use)
- **Zaim API**: 公開規約の第16条第6号は、競合事業や競合商品・サービスの提供を禁止しています。Kakeiroの用途への適用は提供元に確認が必要です。銀行由来の全明細・証券保有資産の取得可否も未確認のため、無料代替と決めて実装を切り替えません。[Zaim API利用規約](https://dev.zaim.net/portal/tos)

Moneytree LINKについても、個人専用・非公開のKakeiroと、将来一般公開する家計簿アプリの両方を想定して利用目的を正確に伝え、適用される契約・利用条件の提供を依頼します。Moneytreeの一般消費者向け利用規約だけで、独自アプリへのAPI利用権を判断しません。

## 指定金融機関の確認事項

対応一覧に機関名があることと、Kakeiroの契約で利用できること、利用者の認証方式で自動更新できることは別です。既存の詳しい調査は[FinancialConnections.md](FinancialConnections.md)にあります。

| 金融機関 | 契約・検証時に確定すること |
| --- | --- |
| SBI証券 | 国内株・米国株・投資信託・NISA・預り金の取得範囲。パスキー必須の口座で接続できるか。 |
| 楽天証券 | 追加認証への対応を最優先で確認。2026年8月20日付の公式案内はログイン追加認証を未対応としている。NISA・外貨・預り金の範囲も確認。 |
| 楽天銀行 | Kakeiroを利用可能な提携アプリとして登録できるか。公式FAQは一部提携アプリのみ、1日1回更新、普通口座のみと説明。0時の更新後、同日中の更新ボタンでは新規取得できない可能性がある。 |
| 三井住友銀行 | 個人口座を対象に、対応科目、履歴期間、更新間隔、再認証周期を確認。法人Web21等とは分けて確認する。 |
| 三菱UFJ銀行 | 三菱UFJダイレクトの個人口座を対象に、対応科目、履歴期間、更新間隔、再認証周期を確認。 |
| ゆうちょ銀行 | 個人口座の対象サービス、残高・明細の取得範囲、更新間隔、再認証周期を確認。 |

証券2社の認証制約は[パスキー公式FAQ](https://help.getmoneytree.com/ja/articles/14320799-金融機関や証券会社のサイトで-パスキー-passkeys-を設定していますが-moneytreeと連携できますか)、楽天証券の追加認証は[非対応機能の公式案内](https://help.getmoneytree.com/ja/articles/7881362-未対応-非対応の金融サービスについて)、楽天銀行の条件は[LINK専用FAQ](https://help.getmoneytree.com/ja/articles/6038789-moneytree-link-楽天銀行への接続はできないのですか)を参照してください。Kakeiroの接続のために認証保護を弱める設定変更を前提にしません。

クレジットカードは**カード会社・カード名が未指定**です。銀行名からカード契約を推測せず、追加したいカードを別途一覧にします。口座番号・カード番号・ログイン情報はこの準備一覧には不要です。

## 0時更新と更新ボタンの意味

毎日0時は**日本時間（Asia/Tokyo）にサーバーが金融機関データの更新を依頼する時刻**です。iPhoneのバックグラウンド実行は指定日時の開始が保証されないため、定時処理は常時動作するサーバー側で行う構成が必要です。[Appleの実行時刻仕様](https://developer.apple.com/documentation/backgroundtasks/bgtaskrequest/earliestbegindate)

Moneytreeへの同期依頼は1利用者あたり1日4回までで、日付は日本時間0時にリセットされます。応答の202は受付を意味し、金融機関からの取得完了ではありません。処理開始まで数分以上かかることや、金融機関の制限で更新されないことがあります。0時の自動更新と更新ボタンはこの同じ制限を共有する設計にします。[同期依頼API](https://docs.link.getmoneytree.com/reference/post-link-profile-refresh)

アプリにはサーバーから取得した時刻と、金融機関データの最終取得成功時刻を分けて表示します。後者は`last_aggregated_success`で確認します。追加認証が必要な口座は利用者の操作が必要で、0時に自動更新を終えられるとは限りません。[口座の日時仕様](https://docs.link.getmoneytree.com/docs/account-metadata)

## 用意する情報

### 申込み前に決める内容

| 項目 | 現在の状態・記入内容 |
| --- | --- |
| 契約主体 | 個人／個人事業主／法人のどれで申し込むか。提供元が必要とする氏名・連絡先等は提供元の正式な窓口へ入力。 |
| 利用範囲 | 自分だけ、家族を含む、将来一般公開する、の予定。現時点で確定していない部分は未定と伝える。 |
| アプリ概要 | Kakeiro：iPhone向けの家計簿・資産管理。自動連携を主、手入力・CSVを補足とする。送金・売買機能は含めない。 |
| 対象 | 上記6機関の個人口座＋追加カード会社・カード名。証券は必要な商品・通貨も列挙。 |
| 利用量 | 利用者数、口座数、初回に必要な過去明細期間、1日1回の定期更新と任意の更新ボタン。 |
| 費用上限 | 初期費用と毎月の上限。完全無料が必須なら、その条件で利用可能なプランがあるかを先に確認。 |
| サーバー | 常時稼働Macでの個人検証、クラウド運用のどちらを検討するか。まずAPI契約可否を確認し、その後に決定。 |
| データ管理 | 国内／海外の保存先、保存期間、解除・削除、バックアップ、端末紛失時の対応を契約条件と照合。 |

### 利用承認後の接続設定

設定値は検証環境・本番環境で分かれます。[環境別の登録仕様](https://docs.link.getmoneytree.com/docs/api-domain)

| 必要な設定 | 入手・設定する場所 |
| --- | --- |
| `client_id`、クライアント種別 | Moneytreeが発行・登録。Public Client／Confidential Clientの区別を確定する。 |
| `client_secret`（発行される構成の場合） | サーバーの秘密設定へ保存。iPhoneアプリへ埋め込まない。 |
| `redirect_uri` | Moneytreeに登録する戻り先と、Kakeiroの実装を完全に一致させる。任意のURLを未登録で使用しない。 |
| OAuthスコープ | `guest_read accounts_read transactions_read request_refresh investment_accounts_read investment_transactions_read`の提供可否を確認。書込みスコープは今回不要。 |
| APIバージョン | 契約・検証で対象バージョンを確定し、`Moneytree-API-Version`に設定。 |
| サーバーHTTPS URL | iPhoneが到達できる接続先。証明書・アクセス認証・保存場所・定期実行を設定。 |
| サーバー認証情報・暗号化鍵 | Kakeiroの運用環境で生成して秘密設定へ保存。プロバイダー認証とは分離。 |
| 利用者の認可・トークン | 利用者がMoneytree公式画面で同意すると取得。`access_token`／`refresh_token`はサーバーで保管・更新。銀行パスワードをKakeiroに渡す作業ではない。 |

秘密値はチャット、README、GitHubに貼り付けず、契約後にサーバーの秘密設定へ直接登録します。ここで必要なのは、発行済みか・どの環境用か・登録した戻り先・承認済みスコープの確認です。

## Moneytreeへの問い合わせ文案（未送信）

件名：個人利用のiPhone家計簿・資産管理アプリ向けLINK APIの契約・料金・対応範囲について

個人で開発しているiPhoneアプリ「Kakeiro」へのMoneytree LINK API導入を検討しています。利用範囲は〔自分のみ／家族を含む／将来公開予定〕、初期利用者数は〔人数〕です。家計簿・資産管理が目的で、送金・証券売買は行いません。API・サーバーとも未契約です。

対象はSBI証券、楽天証券、楽天銀行、三井住友銀行、三菱UFJ銀行、ゆうちょ銀行の個人口座、および〔カード会社・カード名〕です。残高・入出金・カード利用明細・証券保有資産を読み取り、日本時間0時に1日1回の更新を依頼し、必要時はアプリの更新ボタンでも依頼したいと考えています。

以下についてご案内をお願いします。

1. 個人開発者かつ個人専用の家計簿アプリとして契約できますか。Moneytreeと機能が重なる家計簿・資産管理用途について、適用される利用規約・契約条件と、将来一般公開する場合の条件を確認したいです。
2. 無料で利用できる開発・個人利用プランはありますか。なければ初期費用、最低月額、利用者／口座／更新回数に伴う従量料金、最低契約期間、解約条件を教えてください。検証環境の料金・期限・利用可能な実口座も確認したいです。
3. 上記6機関は、この用途・契約で利用できますか。特に楽天銀行の提携アプリ制限と更新制限、楽天証券のログイン追加認証、SBI証券・楽天証券のパスキー必須口座への対応を教えてください。
4. 証券の現金、国内株、米国株、投資信託、NISA、外貨口座について、取得可能な残高・保有明細・取引履歴の範囲を教えてください。円換算額、返金を含む明細金額とカード債務残高の符号規約も確認したいです。
5. 日本時間0時の定期更新と任意更新を併用できますか。`request_refresh`の1日4回制限の適用範囲、金融機関ごとの制限、追加認証を発生させないバックグラウンド更新、受付後の完了確認方法を教えてください。
6. 必要スコープ、iOS＋バックエンドでのPKCE認可、クライアント種別、戻り先URLの登録、APIバージョン、`resource_server`の解釈・許可される接続先を確認したいです。
7. 自分のMacでの検証と、クラウドでの本番運用はそれぞれ可能ですか。データ保存先・暗号化・保存期間・解除／削除・障害時対応・セキュリティ審査など、契約上求められる条件を教えてください。

申込み前の相談窓口は[Moneytree公式FAQ内のコンサルタントへの案内](https://faq.getmoneytree.com/test-environment)から確認できます。上記文案は送信していません。
